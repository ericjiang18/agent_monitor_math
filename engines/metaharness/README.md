# Meta-Harness integration

The website uses the proving adaptation in
[`agent_monitor/runners/metaharness_runner.py`](../../agent_monitor/runners/metaharness_runner.py),
which runs solver, evaluator, and proposer rounds. Configure it through the
console or `METAHARNESS_CMD`.

This directory retains the upstream MIT license and citation. The unrelated
text-classification and Terminal-Bench reference projects, their benchmark
datasets, artwork, and setup files have been moved to the local root `deleted/`
archive. They are not dependencies of the website runner.

Upstream source: https://github.com/stanford-iris-lab/meta-harness
