# Open problem triage

1. Restate the exact target with quantifiers, domains, constants, and requested conclusion.
2. Test the smallest legal cases and every exceptional boundary before choosing a proof strategy.
3. Search current primary sources when known/open status or novelty matters. Verify the exact theorem and hypotheses, not only titles or abstracts.
4. Assign one provisional class: false, known, open, or ill-posed. Record the evidence and the next decisive check.
5. Create named obligations for every imported theorem, finite computation, reduction, and unresolved gap.
6. Pursue a proof only after the false/status checks survive. Prefer an explicit counterexample when one exists.
7. Finish with exactly one outcome: Solved, Counterexample, Known/Open Status, or Partial Progress.

Never infer that a problem is solved from a plausible argument, a bounded search, a green Lean helper theorem, or failure to find recent literature.
